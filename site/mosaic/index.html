    How the image to blocks converter works

    Your picture is shrunk so each pixel becomes one block, from 16 to 256 blocks wide, with the height following the image's shape and capped at 256. Each pixel then gets the Minecraft Java block whose average face color is closest in OKLab, with a small penalty for busy textures. Mostly transparent pixels stay empty.

    Below the preview is the list of blocks you need, most used first, counted in stacks of 64 so you know what to gather. Hover the preview to see which block goes in each column and row. The build command places the whole picture with one command block, split into parts when it is large.

    How do I make pixel art in Minecraft with fewer blocks?

    Lower the block types slider. The tool starts from the blocks a free match would use and keeps the ones that cut the total color error most, weighted by how many pixels they cover. A small area with a distinct color, like an eye, still gets its own block. Fewer types means less detail but an easier build.

    Can I swap a block I do not have?

    Yes. Click a block in the list to see the eight closest colors that pass your filters, and pick one. It replaces that block everywhere in the picture, and you can undo the swap later.

    Should I build it as a wall or a floor?

    Choose wall or floor before you build, because many blocks look different on top and on the side. No gravity blocks is on by default here, so sand and concrete powder will not fall out of a wall.

    Can I see real textures?

    The textures belong to Mojang, so for legal reasons this site does not include or share them. That is why the preview shows average colors. You can still see the real thing: load your own Minecraft client jar or a resource pack and the preview switches to real textures. The file is read in your browser and never uploaded.

    Where do I find my Minecraft .jar file?

    Each game version you have played in the official launcher has its own jar in the versions folder, for example versions/26.3/26.3.jar. The versions folder is in:

    Windows: %appdata%\.minecraft\versions (paste that into the File Explorer address bar).
    macOS: ~/Library/Application Support/minecraft/versions (in Finder, use Go → Go to Folder).
    Linux: ~/.minecraft/versions

    If the version you want is missing, launch it once in the Minecraft launcher and it will appear. Other launchers keep their own copy inside each instance's folder. A resource pack works too: use its .zip as it is.
