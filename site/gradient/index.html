      How the gradient generator works

      Every full, solid block in Minecraft Java 26.3 was measured once: the average color of each face's texture, in linear light, so a log's bark and its cut end count as two different options. There are 460 faces in all. Your colors are blended in OKLab, a color space where equal steps look equal to the eye, and that gives one target color per step.

      Then the whole row is picked at once instead of block by block. Each choice is scored on how close it is to its target, how evenly it steps from its neighbors, whether it repeats a block, and how noisy its texture is. That is why the result reads as one smooth run, not a string of closest matches.

      Can I start from a block I already have?

      Yes. Type a block's name under any color and that block is placed exactly at that point in the row, even if your filters would leave it out. The rest of the row is picked to lead into it and away from it. Change the color again to let go of the block.

      Why does the top or side setting matter?

      Many blocks look different from above than from the side: logs, crafting tables, pumpkins, basalt. Pick top for a floor and side for a wall, and the colors are matched to the face you will actually see.

      What do the filters do?

      Smooth only drops busy textures like logs, bookshelves and glazed terracotta. Survival only leaves out blocks you cannot get without commands, like bedrock and command blocks. No gravity blocks removes sand, gravel and concrete powder, which fall when built in a wall. No light sources removes glowstone, sea lanterns and the like.

      Can I see real textures?

      The textures belong to Mojang, so for legal reasons this site does not include or share them. That is why the swatches show average colors. You can still see the real thing: load your own Minecraft client jar or a resource pack and the swatches switch to real textures. The file is read in your browser and never uploaded.

      Where do I find my Minecraft .jar file?

      Each game version you have played in the official launcher has its own jar in the versions folder, for example versions/26.3/26.3.jar. The versions folder is in:

      Windows: %appdata%\.minecraft\versions (paste that into the File Explorer address bar).
      macOS: ~/Library/Application Support/minecraft/versions (in Finder, use Go → Go to Folder).
      Linux: ~/.minecraft/versions

      If the version you want is missing, launch it once in the Minecraft launcher and it will appear. Other launchers keep their own copy inside each instance's folder. A resource pack works too: use its .zip as it is.
