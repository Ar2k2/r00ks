How the block palette generator works

Every full, solid block in Minecraft Java 26.3 has a measured average color for each face, so a log's bark and its cut end are separate options. Your starting point becomes the base: the block you picked, or the closest block to your color. The palette then turns around the color wheel in OKLab from there, keeping the same color strength, and asks for a few lighter and darker targets at each hue.

Each target gets the closest block that is not used yet, with a small penalty for busy textures, so calm blocks win close calls. Every group is sorted dark to light. Click any block to copy its ID, or use the build command to place it in your world, one row per group.

What do tonal, analogous, complementary and triad mean?

Tonal gives five shades of the base hue, good for depth in one material family. Analogous adds neighbors 30 degrees either side, which feel related but less flat. Complementary pairs two base shades with three blocks from the opposite side of the wheel, for a strong accent. Triad picks blocks 120 degrees away in both directions, the boldest of the four.

How do I find blocks that go together in a Minecraft build?

Start from the block your build is mostly made of, like stone bricks or spruce planks, and try tonal first for trims and shading. Switch to analogous or complementary when you want details that stand out. Set top or side to match whether the blocks go in a floor or a wall, and the filters work the same as in the gradient tool.

Can I see real textures?

The textures belong to Mojang, so for legal reasons this site does not include or share them. That is why the swatches show average colors. You can still see the real thing: load your own Minecraft client jar or a resource pack and the swatches switch to real textures. The file is read in your browser and never uploaded.

Where do I find my Minecraft .jar file?

Each game version you have played in the official launcher has its own jar in the versions folder, for example versions/26.3/26.3.jar. The versions folder is in:

Windows: %appdata%\.minecraft\versions (paste that into the File Explorer address bar).
macOS: ~/Library/Application Support/minecraft/versions (in Finder, use Go → Go to Folder).
Linux: ~/.minecraft/versions

If the version you want is missing, launch it once in the Minecraft launcher and it will appear. Other launchers keep their own copy inside each instance's folder. A resource pack works too: use its .zip as it is.
