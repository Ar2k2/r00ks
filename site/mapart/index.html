Map art

Pick a picture and it becomes map art: a 128 × 128 block area per map, colored so a held map shows your image. Your image is read here in the browser and never uploaded.

Flat is one layer, easy to build. Staircase steps blocks up and down so the map shades them lighter or darker, for three times the colors.

Options
Choose an image to start.

    Build command

    The build starts with a line of cobblestone just north of the art, which the top row's shade is measured against, so the art itself begins 3 blocks south of the command block. To line it up with a map, put the command block on the map's west edge and 3 blocks north of its north edge. Map edges fall every 128 blocks at X and Z of −64, 64, 192 and so on, so for the map around 0, 0 that is X −64, Z −67.
